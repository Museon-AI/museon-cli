# Video content analysis

Use `content-analysis +run` for durable analysis of a supported video URL, Museon Media id, or local video file. It is video-only; use research visual analysis for images, carousels, screenshots, or slideshows. Preserve the returned run id and use `+get` until terminal; `+list` finds prior runs. A submission receipt does not prove analysis completion. Completed results may include a share URL for inspection.

Keep the source identity and analysis run separate. Local files may upload before the analysis starts, so retain the returned Media id when recovery is needed. Do not infer publish, generation, or delivery state from an analysis result.
