# Managed account operations

Use `account-operation` only after reading target accounts and exact schemas. Batch operations must use the batch shortcut exposed by schema instead of repeated single-account writes.

Before submission, resolve niche, reference accounts, research direction, and account conflicts. After submission, inspect created, failed, and existing rows; never report full success without checking each category.

Stopping an operation is a separate terminal change and requires its own explicit approval.

For review, this domain is the source for managed-fleet lifecycle, runs, attribution, and intervention status. Compare planned, generated, and published work with actual outcomes; distinguish performance facts from interpretation and turn the review into a specific next action.
